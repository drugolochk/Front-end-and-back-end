## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина «Нордклавиш»: клавиатуры, свитчи, кейкапы и аксессуары. CSS-фреймворки не используются. JavaScript есть только для открытия и закрытия `<dialog>`.

## Как открыть проект

1. Скачайте или клонируйте репозиторий `kr1-html-css-shop`.
2. Откройте `index.html` в браузере (двойной щелчок или «Open with Live Server»).
3. Сборщик и `npm` не нужны.

## Используемые технологии

- HTML5: семантика, формы, таблица, `<dialog>`
- CSS3: переменные, Flexbox, CSS Grid, позиционирование, БЭМ
- минимальный JavaScript: `showModal()` / `close()` для модального окна

## Обязательные страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | Hero, преимущества (`#advantages`), популярные товары (`#popular`), отзывы, FAQ |
| `catalog.html` | 10 карточек, sticky-фильтр, категории |
| `product.html` | Изображение, описание, цена, таблица характеристик, сравнение трёх моделей |
| `order.html` | Форма заявки |
| `contacts.html` | Адрес, часы, форма обратной связи |
| `about.html` | История, доставка, гарантия |

На каждой странице: уникальные `title` и `meta description`, один `main`, общая шапка и подвал, подключение `css/style.css`.

## Навигация и якоря

Меню одно и то же на всех страницах. Проверяемые переходы:

- главная → каталог, товар, заявка, контакты
- каталог → главная, товар, заявка, контакты

Якорные ссылки:

- `index.html#advantages` — преимущества
- `index.html#popular` — популярные товары
- `index.html#contacts` — подвал с контактами

Фильтр каталога тоже якорный: `#keyboards`, `#switches`, `#keycaps`, `#accessories`.

## Модель товаров (задел под КР №4, №5 и бэкенд)

У карточек единые атрибуты:

```html
<article class="product-card"
         data-id="1"
         data-category="keyboards"
         data-price="18990"
         data-available="true">
```

Категории: `keyboards`, `switches`, `keycaps`, `accessories`.

Поля формы заявки совпадают с будущим API: `name`, `email`, `phone`, `productId`, `comment`, `consent`. `action="#"` — без сервера.

Каталог **не** генерируется JavaScript: в КР №1 карточки написаны в HTML, как требует методичка.

## Что сделано по методичке

- семантика: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- карточки товаров с названием, описанием, ценой, кнопкой «Подробнее» и бейджами
- таблица с `caption`, `thead`, `tbody`, `th`, `td`
- форма с `label` + `for`/`id`, `name`, `required`, `type="email"`
- модальное окно `<dialog>`
- CSS-переменные в `:root`
- состояния `:hover`, `:focus-visible`, disabled
- Flexbox (шапка, меню, кнопки) и CSS Grid (hero, каталог, карточки)
- БЭМ: `site-header`, `site-nav`, `product-card`, `order-form` и модификаторы
- позиционирование: `relative` (карточка), `absolute` (бейдж), `sticky` (меню и фильтр), `fixed` (кнопка «Наверх»), `z-index` (модалка)

## Самостоятельные доработки

- своя визуальная концепция: тёмно-синий фон и медный акцент, не палитра из методички
- страница `about.html`
- блок отзывов и FAQ на главной
- хлебные крошки на карточке товара
- модификаторы карточек: хит / новинка / скидка / нет в наличии
- sticky-фильтр каталога и кнопка «Наверх»
- сравнительная таблица Aurora / Frost / Tundra
- skip-link, видимый фокус, осмысленные `alt`
- SVG-иллюстрации без чужих фотографий
- данные товаров и полей формы сразу в формате будущих КР
